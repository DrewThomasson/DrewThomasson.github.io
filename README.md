# Drew Thomasson — Portfolio

Personal portfolio for [Drew Thomasson](https://github.com/DrewThomasson), highlighting open-source AI, media, and developer-tool projects.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The included GitHub Actions workflow deploys the site to GitHub Pages whenever `main` is updated. In the repository settings, set **Pages → Source** to **GitHub Actions**.
